<h1>📸 Gestor de Comprovantes com IA</h1>

<p>O <strong>Gestor de Comprovantes com IA</strong> é uma aplicação web desenvolvida para simplificar o controle financeiro diário. Através do upload ou foto de um comprovante de compra, o sistema utiliza Inteligência Artificial para interpretar a imagem, extrair os valores e registrar as despesas de forma 100% automática.</p>

<h2>✨ Funcionalidades</h2>

<ul>
  <li>📎 <strong>Upload de Arquivos:</strong> Suporte para anexar imagens de notas fiscais já armazenadas na galeria.</li>
  <li>🤖 <strong>Leitura Inteligente:</strong> IA integrada que escaneia o documento e reconhece os produtos comprados.</li>
  <li>💰 <strong>Extração de Valores:</strong> Identificação automática do preço de cada item e do valor total do cupom.</li>
  <li>📊 <strong>Dashboard de Despesas:</strong> Painel prático que exibe o histórico somado de todos os gastos registrados.</li>
</ul>

<h2>🔄 Como Funciona?</h2>

<ol>
  <li><strong>Envio:</strong> O usuário tira uma foto e anexa a imagem do comprovante.</li>
  <li><strong>Análise:</strong> A imagem é processada pela Inteligência Artificial.</li>
  <li><strong>Extração:</strong> O sistema isola os textos, nomes de produtos e preços.</li>
  <li><strong>Processamento:</strong> A aplicação calcula automaticamente o novo balanço total.</li>
  <li><strong>Visualização:</strong> Os dados organizados e somados aparecem instantaneamente na tela.</li>
</ol>
